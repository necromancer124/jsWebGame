# Vanilla Skyrim - Mini RPG

Browser RPG built with HTML, CSS and JavaScript.

## Controls
WASD / Arrows = Move
Space = Attack
Shift = Dash
Q = Dragon Shout
E = Open Chest
P = Pause
M = Mute

## Features
- Loot system
- Boss fight
- Potions
- Ghost souls
- Furry Ork (uwu)
- Background music

Open index.html to play.
